# 文境寻踪 · 华夏文脉

AI 驱动的汉字文化沉浸式解谜游戏。四时代穿越，五身份体验，三十六字寻踪。

## 功能特色

- **四时代场景**：先秦·鸿蒙初文 / 汉唐·长安诗会 / 宋明·园林雅聚 / 近现代·传承之境
- **五文心身份**：寻字者、吟游者、天工者、知俗者、明心者
- **描摹汉字**：亲手描画甲骨文，感受笔画间的文明温度
- **会意字谜题**：拼合部件，理解汉字的构形智慧
- **仓颉对话**：与造字之神对话，追问汉字的来处
- **离线可用**：单文件部署，无需网络即可畅玩

## 技术栈

Vite + React 18 + TypeScript + zustand + DeepSeek API
